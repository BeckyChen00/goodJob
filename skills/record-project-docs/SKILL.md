# 项目文档记录

执行前确认静态检查、相关功能测试和生产构建均已通过；否则停止且不得修改文档。

## 功能迭代文档

在 `功能迭代文档.md` 的“迭代记录”顶部追加：

- 标题严格使用 `## [yyyy-mm-dd] 功能名称`。
- 简述用户可感知功能、关键实现和验证结果。
- 不覆盖历史，不记录尚未完成的计划。

## 技术与需求交接文档

更新 `技术与需求交接文档.md`，同步当前真实的需求状态、架构、数据模型、关键文件、运行测试方式、限制、风险和待办事项。删除失效描述，但保留必要迁移说明。

使用本地日期，禁止写入密钥、个人数据或虚构测试结果。交付时指出更新的条目。
