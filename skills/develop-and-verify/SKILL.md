# 高优开发与测试

1. 阅读 `技术与需求交接文档.md`、相关代码、现有测试和 `package.json`。
2. 明确验收标准、影响范围、数据兼容性和失败风险。
3. 设计覆盖正常路径、边界条件、错误路径和回归风险的测试用例。
4. 以最小完整改动实现功能，保留用户数据兼容性。
5. 将可自动化用例写入测试文件，避免只在回复中描述。
6. 执行静态检查、相关功能测试和生产构建。以项目现有命令为准；本项目至少执行 `npm run lint`、`npm test` 或等价测试，以及 `npm run build`。
7. 发现失败时修复并重跑，不得忽略失败或降低断言标准。
8. 全部必需测试通过后，继续执行 `skills/record-project-docs/SKILL.md`。
