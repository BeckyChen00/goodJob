# 求职投递台 Chromium 扩展

## 构建与加载

运行 `npm run build:extension`，然后在 Chrome/Edge 扩展管理页启用开发者模式并加载 `extension/dist/`。每次更新后都要点击扩展的“重新加载”。主应用需运行在 `http://localhost:3000/`。

## AI 填写与添加到投递台

1. 在招聘岗位页打开插件，点击“设置”。
2. 填写 DeepSeek API Key 和模型，默认模型为 `deepseek-chat`。
3. 点击“AI 一键填写”。任务会在扩展后台继续运行；切换页面或关闭弹窗后，回到同一招聘 URL 会恢复处理状态、AI 结果及手工修改的表单。
4. 核对并可修改所有字段。可选择“企业＋岗位”或“仅添加企业”；AI 没有识别到岗位名称时会自动选择仅企业模式。AI 只回填表单，不会提交。
5. 用户点击“添加到投递台”后才发送。仅企业模式不会创建空岗位；成功时显示“已提交”弹窗并写入管理页 IndexedDB，失败时保存在“发送失败的草稿”中。

API Key 只保存在扩展的 `chrome.storage.local`，不得提交到源码或截图中。插件会把裁剪后的当前页面 HTML 发送给 DeepSeek，请勿在包含无关敏感信息的页面使用。

## 测试

运行 `node --test extension/tests/*.test.mjs` 执行插件测试。完整仓库验证使用 `npm run lint`、`npm test` 和 `npm run build`。

## 维护与填充简历

在已登录的简历编辑页面打开插件，点击“维护简历信息”。插件会提取当前页面原生表单字段并合并到右侧抽屉，value 默认留空；可手工修改、新增、删除并保存。点击“一键填充简历”后才会写入当前页面，插件不会上传附件、处理验证码或点击提交。

插件还会加载仓库中的 `resume-data/resume-profile.json`，当前包含 26 个空值常用字段。可直接编辑该 JSON 并提交到 Git；这会把 value 永久明文记录在仓库及历史中。抽屉中的“保存”只写浏览器本地副本，不会回写仓库文件。

规则匹配不足且已配置 DeepSeek 时，只会发送网页字段元数据和简历 key 用于映射，不发送简历 value。姓名、电话、身份证等内容以明文保存在浏览器扩展本地存储中，请仅在可信个人设备使用。
