# 求职投递台

一个仅在本机浏览器保存数据的企业与岗位投递管理页面。

## 启动

首次运行：

```powershell
pnpm install
pnpm dev
```

浏览器打开终端显示的本地地址（通常为 `http://localhost:3000`）。以后只需执行 `pnpm dev`。

## 数据保存在哪里

数据保存在当前浏览器、当前站点地址对应的 IndexedDB 数据库 `job-application-tracker` 中。首次打开会自动创建数据库并导入预置企业，不需要数据库服务、账号、环境变量或额外配置。

请保持访问地址一致：`localhost`、`127.0.0.1` 和不同端口会被浏览器视为不同站点，彼此看不到数据。清除该站点的浏览器数据也会删除记录，因此建议经常使用页面右上角的“导出备份”。
